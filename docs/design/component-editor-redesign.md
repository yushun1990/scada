# 组件编辑器：布局与视觉修正

日期：2026-09-16。状态：按小批次提交与验证，见 [后续批次记录](../progress/component-editor-followup-2026-09-16.md)。接续 [Web 编辑器简化修正](web-editor-simplification.md)，以浏览器中的组件创作任务组织界面。

## 操作位置

| 区域 | 修正后的职责 |
| --- | --- |
| 页头左侧 | 返回工作台、文档名称；长名称省略并可查看完整名称 |
| 页头画布中央 | 唯一的设计／预览切换 |
| 页头右侧 | 保存与保存状态、发布 |
| 画布工具栏第一组 | 复制、删除、撤销、重做、组合／拆分 |
| 第二组 | 对齐、分布；空间不足时整组迁入一个菜单，不同时显示两套入口 |
| 第三组 | 吸附、网格、网格尺寸 |
| 每个图层行 | 置顶、上移、下移、置底；选中、悬停或键盘焦点时可见 |
| 两侧边缘 | 收起／展开面板；拖动分隔线调宽，双击或按 Enter 恢复该侧默认宽度 |
| 右侧属性面板 | 所选内部图层的配置；组件契约在中央组件工作页编辑 |

组合／拆分保留在画布工具栏，不移到图层面板。它改变结构，属于当前选择的编辑命令。图层排序直接贴近目标图层；列表按前景在上展示，使“上移”同时对应列表和画布的前后关系。存储模型和渲染顺序不变，继续调用现有排序与分组命令；同级多选保留相对顺序。画布命中和拖动选择最外层组合；树可选择组合内部图层编辑属性与行为，但位置、尺寸、形状和拖动必须先拆分后修改。

页头 44px、画布工具栏 36px。工具栏只跨画布区域，三组均衡分配空间；侧栏从页头下方开始。对齐区域根据实际容器宽度收纳，不仅根据窗口宽度判断。1000px 窗口保留双侧栏时可使用对齐菜单；600px 验证需通过边缘按钮收起侧栏，不宣称已经完成移动端适配。

白色画板按中央可用区域等比适配，移除原 720×520 显示上限，外侧留白由 32px 收为 16px。不更改组件的设计坐标、默认尺寸或已保存内容。侧栏收起后保留可见展开入口，显隐和宽度继续通过现有偏好存储保存。

## 视觉与信息密度

- 使用浅中性灰与低饱和青绿色：画布 `#e8edeb`、面板 `#fafbf9`、强调 `#137766`、选中底色 `#e1f1e9`。保存、模式、焦点、图层选择和画布控制柄统一使用主题 token。画布内容自身配色不由界面主题改写。
- 基础图元使用同一套 SVG 线性图标，20px 图形置于足够的点击区域内。常态没有大方框；悬停与选中用浅色底反馈，保留名称提示、双击居中和拖拽创建。
- 图层类型采用对应小图标，释放名称宽度，避免“矢量图形”等类型文本被截成无意义的省略号。
- 属性面板使用平面分区、32px 分组标题、28px 常规字段。清除旧样式叠加的字段外边距，尺寸与几何保持并排输入。
- 当前界面以中央“图形化设计／Coding 开发”切换画布与组件工作页；右侧固定检查所选内部图层，空选择显示选择提示。切换工作页保留画布选择及各自页签。组件区编辑 Attributes、Properties 和 Anchors；可移植用户组件的方法／事件标为“未开放”，旧声明仅供查看与显式删除，不提供新增、实现编辑或执行。可信内置组件仍可由宿主提供 Actions/Events。图层区提供属性、声明式行为（视觉规则、动画）；SVG 状态绑定生成 Property 和私有规则。这替代早期“同一检查器切换组件／图层”的布局描述，不改变当前执行能力边界。
- 静态配置、运行属性、连接点使用任务语言；远端发布详情移至常用配置之后。删除纯实现说明，不更改契约模型。

主题只在组件编辑器挂载时生效，并覆盖 Portal 菜单；退出组件路由后恢复共享默认主题。组态编辑器继续采用第一阶段的精简页头与全宽工具栏。
