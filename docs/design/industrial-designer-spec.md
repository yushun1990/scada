# SCADA Studio 工业设计工作台 UI 规范

版本：1.0 · 2026-09-10。

状态：本次审计提出的修正规范，作为后续 UI 改造的目标基线；不表示当前实现已经符合。运行时、Schema、存储与分发继续遵守已接受的 M6–M9 / UX1 架构。

本规范替代旧 UI foundation / editor-ui 中冲突的视觉、尺寸与 Inspector 布局约定。[审计依据](ui-audit-2026-09-10.md)；[实施计划](industrial-designer-rollout.md)。

## 1. 产品定位与参考方式

服务对象是使用鼠标键盘进行长时间组态与组件开发的工程师。核心质量要求是定位准确、修改范围明确、可撤销、保存状态可信、异常可追踪。

参考 Ignition Designer 的菜单、资源浏览器、属性编辑器和可恢复布局；具体像素、色值、中文术语与模块组织由本项目定义。采用同一 Shell 支撑 SCADA 与 Component 两种工作空间。[Ignition Designer 工作空间与停靠系统](https://docs.inductiveautomation.com/docs/8.3/platform/designer/designer-user-interface)

### 2.1 尺寸

全部为 CSS px；以下是项目设定，不是 Ignition 实测尺寸。

| 项目 | 默认 | 约束 |
| --- | --- | --- |
| 菜单栏 | 28 | 项目名截断可展开查看；不挤压菜单和保存状态 |
| 主工具栏 | 36 | 固定一行，低频命令进入溢出菜单 |
| 文档条 | 28 | 名称、类型、dirty、关闭；长名省略但可查看完整路径 |
| 面板标题 / 分组标题 | 28 | 无卡片外边距；分隔线表达层级 |
| 状态栏 | 26 | 布局独立行，不能遮住画布 |
| 左侧面板 | 248 | 可调 208–360；上半 Palette/作品、下半 Navigator |
| 右侧 Inspector | 320 | 可调 280–440；列表与复杂详情可展开 |
| 常规控件 / 属性行 | 28 | 不随文字缩小；内部图标 16 |
| 树行 / 紧凑工具按钮 | 26 | 点击区域至少 24×24，关注完整命中区域 |
| 宽松密度控件 / 树行 | 32 | 保持相同信息结构，字号不小于默认值 |
| 左右分隔拖动区 | 6 | 支持焦点与方向键调整，实际线条 1 |
| 折叠面板条 | 28 | 明确名称，点击或键盘展开 |
| 常用间距 | 4 / 8 / 12 / 16 / 24 | 2 / 6 仅用于图标微间距、分隔拖动区等已定义用途 |

1366 宽的默认布局中，中心可用宽度约 `1366 − 248 − 320 − 12 = 786`。设计验收基准包括 1366×768；非画布部分不得出现页面级横向滚动。

可用宽度低于 1200 时压缩低频工具进入菜单；低于 1100 时左面板默认折叠并允许用户展开；中心保持至少 480 宽，必要时仅允许一个侧边面板占据布局。低于 900 时面板以互斥覆盖层打开，可关闭恢复画布，不将三栏堆成纵向长页面。窄视口仍允许保存、返回、打开属性与运行预览；完整精细绘图体验以桌面基准验收。

展开面板必须获得焦点；关闭后回到触发按钮。首次默认布局和用户偏好分开管理；“视图 → 重置布局”始终可达。偏好通过现有存储抽象保存，不进入 Scene 或组件包。

### 2.2 固定职责

- 菜单：完整命令入口；工具栏：高频命令；右键菜单：当前对象命令。三者调用同一个命令接口。
- 左侧：创建与定位；中部：当前文档；右侧：所选对象配置；底部：持久状态和可展开问题列表。
- Component 工作台保留创建区与真实图层导航；组件级配置通过“组件设置”进入，不添加伪造根图层。
- SCADA 工作台补真实 Scene Navigator。作品/组件导航只是既有 Repository 的投影，不新增工程模型。

## 3. 颜色与材质

浅色中性灰为首轮基线。面板无装饰渐变、无常驻大阴影；画布内容与 UI chrome 的颜色分开管理。

| 目标 token | 值 | 用途 |
| --- | --- | --- |
| `--ui-color-app-background` | `#e8eaed` | 工作台底色 |
| `--ui-color-panel` | `#f2f3f5` | 工具区、Inspector |
| `--ui-color-surface` | `#ffffff` | 可编辑输入、菜单、文档 |
| `--ui-color-surface-subtle` | `#f7f8fa` | 次级表头与局部背景 |
| `--ui-color-canvas` | `#c9cdd2` | 画板外工作区 |
| `--ui-color-text` | `#202428` | 主文字 |
| `--ui-color-text-secondary` | `#52565e` | 标签与帮助 |
| `--ui-color-text-subtle` | `#626872` | 次要说明；逐背景校验 |
| `--ui-color-text-muted` | `#626872` | 可读元信息；不再兼作 disabled 色 |
| `--ui-color-text-disabled` | `#8a9099` | 真正不可用的控件 |
| `--ui-color-border` | `#c4c8ce` | 非关键分组分隔 |
| `--ui-color-border-strong` | `#858c96` | 识别输入边界所必需的边框 |
| `--ui-color-accent` | `#1769aa` | 焦点、主动作、选择边 |
| `--ui-color-accent-hover` | `#12568e` | 主动作 hover |
| `--ui-color-accent-pressed` | `#104773` | 按下反馈 |
| `--ui-color-accent-soft` | `#e7f0fa` | 选中行背景 |
| `--ui-color-success` | `#287a45` | 保存/校验成功的图标，附文字 |
| `--ui-color-warning` | `#9a6700` | 警告与待处理图标；说明文字使用 text / text-secondary |
| `--ui-color-danger` | `#b42318` | 编辑错误、删除动作，附文字 |

所有现有 token 在迁移时逐一映射，未列出的 surface-muted、border-subtle、accent-soft-strong 等不得自行保持一套并行色系。先建立状态样本页再切换两编辑器。

色值复核：`text-subtle` / panel 为 5.05:1，`border-strong` / panel 为 3.06:1；warning / panel 仅 4.38:1，不用于该背景上的普通文字。这些是不透明色值的计算结果，不能代替实际计算样式与状态样本验收。

颜色状态规则：

- 普通按钮中性；同一命令区通常只突出“保存”或当前对话框的确认动作。
- 选中行 = 浅蓝底 + 深色字 + 选择标志；键盘焦点 = 2px 清晰外框；两者可同时出现。
- 模式切换采用相邻的“设计 / 预览”两片，无额外厚背景壳；选中片浅蓝，状态栏同时显示模式。
- disabled 与 read-only 分别表达：“不可用”淡化；“只读”保留可读对比度且值可复制。
- 连线、阀门、泵的过程状态色来自运行主题，不复用编辑器 accent 作为报警语义。

普通文字最低 4.5:1；识别控件/状态所必需的非文字部分至少 3:1。装饰分隔线与 disabled 不应被误当作同一检查对象。[文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[非文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)

## 4. 字体、图标与密度

| 内容 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 工作台标题 | 18 / 24 | 600 |
| 文档标题、面板标题、正文 | 13 / 20 | 400–600 |
| 菜单、工具提示、属性标签与值 | 12 / 18 | 400；组标题 600 |
| 辅助说明、状态、技术 key | 11 / 16 | 400 |

Chrome 不使用 8/9px。11px 不能承载必须读懂才能操作的长说明；长说明使用 12px 并允许换行。中文优先系统可用字体：`system-ui, "Segoe UI", "Microsoft YaHei", "PingFang SC", sans-serif`。坐标、数值采用 tabular-nums；DSL、路径和 key 使用等宽字体并支持复制。

图标基于现有 SVG 系统统一 16×16，常规线宽 1.5；不混用 emoji、Unicode 几何字符和字母头像作为正式工具图标。名称不足以辨认的组件用真实简化符号或真实缩略图。

圆角：面板 0，输入/按钮 2，浮层 4。普通状态不使用胶囊标签。阴影仅用于菜单、弹层和浮动工具，最多一层。控件命中区域至少 24×24；更小的视觉图形必须置于足够的点击容器中。这是本项目的基线；WCAG 本身还规定了间距等例外。[Target Size Minimum](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)

## 5. 文档与命令

### 5.1 文档身份与保存

文档条显示“名称 · 类型”，有修改显示 `*` 并提供“未保存”可访问文本。底部显示：未保存 / 保存中 / 已保存 HH:mm / 保存失败。

保存只在持久化成功后更新 saved revision。异步保存期间继续编辑时，保存完成仅确认提交的 revision，较新的编辑继续保持 dirty。失败保留数据、显示错误与重试/导出入口。

返回工作台、打开其他文档、关闭文档：dirty 时使用“保存并继续 / 放弃修改 / 取消”。刷新、关闭浏览器使用浏览器支持的未保存提示；不能依赖卸载阶段异步写入作为保存保证。场景 `.scene.json` 标为“导出场景结构（高级）”，完整作品 `.scada-work.json` 为普通“导出作品”，说明实际导出的是当前版本还是已保存版本。

### 5.2 命令和快捷键

| 范围 | 命令 |
| --- | --- |
| 文件 | 新建、打开/返回、保存 Ctrl/Cmd+S、导入、导出 |
| 编辑 | 撤销 Ctrl/Cmd+Z、重做 Ctrl/Cmd+Shift+Z、复制/粘贴、生成副本 Ctrl/Cmd+D、删除 |
| 视图 | 缩放、适合画板、适合所选、网格、连接点、显示面板、重置布局 |
| 插入 | 当前工作空间实际支持的组件/图元/文件导入 |
| 排列 | 对齐、分布、组合 Ctrl/Cmd+G、取消组合 Ctrl/Cmd+Shift+G、层级 |
| 运行 | 设计/预览、当前会话数据、已有诊断 |
| 帮助 | 使用说明、快捷键、存储诊断 |

未实现的能力不显示可执行入口。命令带 enabled / disabledReason / checked；按钮与快捷键共享检查。文档变更命令统一通过事务入口，不能只在按钮上 disabled。

输入、textarea、contenteditable、IME 合成期间不拦截文本编辑快捷键。Space 平移只在画布交互上下文生效，不能因鼠标悬停画布而吞掉输入框空格。Escape 优先取消正在编辑的字段/弹层，然后结束创建工具，最后清除画布选择。

### 5.3 编辑事务

一次拖拽、一次数值输入确认、一次组合或一次绑定保存对应一条撤销记录。字段 Enter / blur 提交有效值；Escape 恢复编辑前值；非法值保持输入并显示字段错误，不能将空字符串静默转成 0。菜单执行前要处理未提交字段，确保保存与模式切换不会漏掉最后一次输入。

Component 与 Scene 共用命令/事务接口约定，各自保留领域状态；不是把两个 Schema 合成一个。当前缺失的 Component 文档撤销也应覆盖图层、公开契约与规则，并随现有引用协调逻辑一并恢复。

## 6. 导航与创建

SCADA Navigator 以真实 Scene node / connection 为数据源，支持搜索名称、类型与 key、展开组合、定位所选、选择联动、显隐与锁定状态。Component Navigator 保留真实 VisualLayer forest，托管 SVG 内部选择继续使用现有目标权威。

树行采用缩进 16、单行名称、末尾状态图标。单击选择，方向键移动/展开，Home/End 跳转，F2 重命名适用对象，Ctrl/Cmd 多选，Shift 连续选择。隐藏、锁定、绑定异常的状态有可访问名称。树侧操作调用现有领域命令，不创建第二套层级数据。

Palette 按基础图元、工业设备、显示、用户组件分类；搜索名称/类型；空结果提供清除搜索。保持现有点击创建/画布放置流程并明确当前创建工具，Escape 退出。多选组合只从排列命令创建 Group。

## 7. 属性检查器

### 7.1 结构与选择上下文

固定顺序：上下文标题 → 搜索 → 配置/动作/事件 → 可折叠分组 → 字段。整体只有一个主纵向滚动区；分组标题固定高度；不把每个字段包成独立卡片。

| 当前选择 | Inspector 内容 |
| --- | --- |
| SCADA 空选择 | 场景名称、尺寸、背景；无虚构组件属性 |
| 单组件实例 | 标识与几何 → 静态配置 Attributes → 运行属性 Properties → 显示 |
| 多选 | 数量与共同字段；混合值显示“多个值”，布尔三态；一次修改明确作用于 N 个对象 |
| 连接线 | 名称、端点、路径、线型、方向；无组件契约标签 |
| Component 无图层选择 | 组件信息、尺寸、Attributes / Properties 契约、动作/事件契约、连接点 |
| Component 图层 / SVG 元素 | 选择路径、几何、样式、适用规则/动画；组件设置保留独立入口 |
| 内置只读组件 | 完整可读配置与“内置 · 只读”，复制值仍可用 |

“动作 / 事件”选择时若作用于组件文档而非内部图层，上下文标题必须同步说明，不能看似仍在编辑该图层。多选不默认露出最后选中对象的单选表单。

### 7.2 属性行

```text
标签 / 单位             设计值或当前值        状态/绑定
出口压力 (kPa)          245.0                 [绑定]
  来源：模拟压力   当前值：245.0   设计值：0.0
```

默认行高 28；标签列约 40%，值列弹性，末尾操作区 28。对象/数组/DSL/长文本通过展开详情编辑。搜索不改变数据；匹配字段所在分组自动展开，清除后恢复原折叠状态。

- Attributes：静态配置；不提供运行绑定按钮。
- Properties：分别显示设计值、是否绑定；预览时显示会话有效值与来源，不能把当前有效值写回设计值。
- 绑定按钮在键盘聚焦时可见；已绑定或异常状态常驻。点开包含类型兼容来源、来源说明、预览与应用/取消的详情。
- 缺失来源与类型不匹配显示具体错误；用户可定位/替换/解除。只有适配器真实提供质量和时间戳时才显示；否则写“未提供”，不能编造“Good”。
- 原始 key 可复制并在高级详情显示，默认标签使用用户语言。

逐属性入口借鉴 Ignition 的属性绑定交互；本项目仍严格保留 Attributes / Properties 的权威区分。[Perspective Property Editor](https://docs.inductiveautomation.com/docs/8.3/ignition-modules/perspective/perspective-designer-interface#perspective-property-editor)

## 8. 设计、预览与独立运行

| 行为 | 设计 | 预览 | 独立运行 |
| --- | --- | --- | --- |
| 修改布局/静态配置/绑定定义 | 允许 | 禁止 | 禁止 |
| 修改临时模拟值 | 不进入持久文档 | 允许适用会话值 | 由既有 runtime 能力决定 |
| 执行组件动作/事件 | 按既有设计规则 | 按既有受控运行能力 | 按既有宿主能力 |
| 保存作者文档 | 允许 | 可保存设计快照；不得混入预览覆盖值 | 不提供 |
| 对外命令 | 不因 UI 改版新增 | 只反映已有宿主能力 | 只反映已有宿主能力 |

模式、来源和连接/模拟状态分别表达。无真实连接时显示“模拟数据”或“未接入”，不显示暗示在线的绿色圆点。预览中禁用所有设计变更命令，仍允许选择查看、缩放、复制只读值和退出预览。

Standalone 保持独立、只读的产品面；空状态改成“加载作品包”，解释用户需要做什么。移除 M8 与内部实现说明，依赖详情放在“作品信息”。

## 9. 运行 HMI 的视觉边界

以下适用于新示例与未来运行主题，不强制重写用户已创作的作品：

- 正常设备使用可辨识的中性轮廓、名称与状态文字；关键数值带单位、量程或参考信息。
- 故障/告警以设备附近的形状、文字、颜色共同表达；颜色不能成为唯一判断依据。
- 运行/停止、故障、通信质量是独立维度；“断连/未知”不可显示为正常或数值 0。
- 真实系统未定义报警优先级、确认、搁置能力时，不添加貌似可用的按钮和状态。
- 避免装饰性闪烁；动态效果只表达真实语义。工业触屏采用独立更大的触控密度，不能直接沿用 Designer 的 28px 控件。

这些方向参考官方高性能 HMI 实践，具体工艺与告警映射需由实际工程定义。[Ignition High Performance HMI Techniques](https://www.docs.inductiveautomation.com/docs/8.1/ignition-modules/vision/common-tasks-in-vision/high-performance-hmitechniques)

## 10. 工作台、反馈与术语

Workspace 默认表格：名称、类型、更新时间、规模/状态、操作；搜索和排序放在表头。可切真实缩略图视图；无缩略图时用明确的文件符号，不显示伪造场景预览。空状态提供“新建 / 导入”，加载失败提供重试。

保存/命令反馈在状态栏；短暂成功提示不抢焦点。错误不能被普通消息自动覆盖；可展开问题区显示对象、字段、原因和定位动作。第一版只聚合真实已有校验/导入/保存结果，不另造报警引擎。

存储诊断、调试快照、重置本地数据位于“帮助/工具 → 存储管理”。重置保留明确不可撤销说明与确认，使用 danger 动作；普通编辑命令通过撤销恢复。

## 11. 实现约束

1. 保留 Base UI 与 `src/ui` 边界；新增 Menu、Dialog、Tree、PropertyRow、StatusBar、SplitPane 时先建立 Studio 封装。
2. 共享 `StudioShell` 接收身份、菜单、命令、左右面板、文档和状态插槽；移除 DOM 查询式 toolbar 注入。
3. CSS 层级目标：reset → legacy → tokens → primitives → shell → feature；明确 layer 顺序，逐区域搬迁/删除旧规则。不能仅包新 CSS 而让未分层旧规则继续覆盖它。
4. primitive 决定字号、颜色、focus、disabled 与控件几何；feature 只负责组合布局和领域状态。不新增 `button:first-child`、全局 `button` 或更长选择器来修正语义。
5. 不改变 Scene/Component/package schema；UI 状态、布局偏好和临时模拟值分别管理。Schema 外的持久偏好使用现有 Repository 边界。
6. 不引入第二个 Renderer、runtime value authority、SVG target authority 或隐藏组件安装流程。
7. 保留已有模型和浏览器验收；新增检查针对真实风险，不以“原生控件数量为零”代替可访问性或视觉测试。

## 12. 完成标准

- 所有 A01–A06 的 P1 条目通过对应任务验证；预览和多选无不明确写入路径。

- 所有普通文字至少 11px，常规字段 12px；真实颜色组合满足目标对比度。
- 基准分辨率无操作被遮挡、工具栏溢出有菜单、错误可见、焦点可找回。
- 保存、撤销、导入导出、包依赖、只读运行与 SVG/图层选择保持原有语义。
