# M6.2.5 Compact Inspector Density

Status: implementation complete · PR pending · manual visual smoke pending.

This slice follows M6.2.3 contextual Properties and M6.2.4 shared collapsible groups. It does not change any Component or Scene data contract; it only makes the shared right-side Inspector denser and closer to mature graphics editors such as draw.io and Inkscape.

## Goal

Keep the established structure:

```text
Properties | Actions | Events
        ↓
collapsible property groups
```

but replace padded card-form presentation with a compact tool-palette presentation:

```text
▾ Geometry
X  [ 12 ]   Y  [ 18 ]
W  [ 80 ]   H  [ 64 ]
Rotation     [  0 ]
────────────────────
▾ Display
☑ Visible    ☐ Locked
```

## Completed in code

- Added one shared `src/inspector-compact.css` density layer consumed by both Component Workbench and SCADA Workbench.
- Collapsible groups now use thin separators rather than independent rounded cards.
- Group headers are shorter while retaining the existing shared expand/collapse behavior.
- Standard property rows use left label + right editor layout to avoid wasting a full row on labels.
- Numeric property grids keep compact paired editors for geometry and size fields.
- Checkbox rows no longer render as padded card-like blocks.
- Text/select/number/color controls use shorter heights and tighter padding.
- Scene summaries, multi-selection summaries and component implementation notes use the same compact density.
- Component public-contract editors are also compacted so nested Property/Action/Event/Anchor authoring does not reintroduce large form spacing.
- The density layer is presentation-only and does not persist UI layout state.

## Architecture boundary

No changes to:

- `SceneDocument`
- `ComponentDefinition`
- `ComponentVisualDefinition`
- runtime bindings
- Action/Event behavior
- Component Registry
- Component Package persistence
- undo/redo semantics

## Manual visual smoke after merge

- right-side Properties show substantially more useful rows without scrolling
- group headers remain easy to identify and click
- labels and editors remain readable without clipping important values
- geometry/size pairs remain usable at the existing inspector width
- textarea and long descriptions remain usable despite the compact row layout
- Component public Properties/Actions/Events/Anchors remain editable
- Preview/read-only states remain visually clear
- no field value or saved data changes merely by using the new compact styling
