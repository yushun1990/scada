# M6.2.9 Studio Navigation Model

Status: implementation complete · PR pending · manual navigation smoke pending.

This slice establishes one navigation model for SCADA Studio before the UI foundation is frozen. It changes route/chrome behavior only; editor data, Scene, Component and Runtime contracts are unchanged.

## Decision

Studio editors are normal routes in one application, not separate browser-tab applications.

```text
#/works
  -> SCADA works workspace
  -> #/scada/:workId

#/components
  -> component library workspace
  -> #/components/:componentId
```

The default transition stays in the current browser tab. Browser history therefore represents real Studio navigation and Back/Forward can return between workspace and editor contexts.

## Completed in code

- `AppRoute` now distinguishes `#/works` and `#/components` workspace modules.
- `WorkspacePage` receives its active module from the route instead of keeping module selection only in local React state.
- Workspace sidebar navigation writes the corresponding hash route.
- Opening or creating a SCADA work now navigates to `#/scada/:workId` in the current tab instead of calling `window.open(..., '_blank')`.
- Component open/create keeps the same current-tab route model.
- SCADA work cards no longer describe the action as “new tab edit”.
- Both editors receive one App-owned low-emphasis `工作台` exit in the far-right header lane.
- SCADA Editor exits to `#/works`.
- Component Editor exits to `#/components`.
- The Component Editor's old left-side back arrow is removed from presentation so navigation no longer contaminates the identity block.
- The center Design / Preview grid column is not moved; the right toolbar reserves space for the shared workspace exit instead.

## Architecture boundary

No changes to:

- SceneDocument or scene persistence
- ComponentDefinition / ComponentVisualDefinition
- Component package persistence
- Registry
- Runtime / bindings / behaviors
- undo/redo
- renderer behavior

## Manual smoke after merge

- opening/creating a component stays in the current tab
- browser Back returns from SCADA Editor to `#/works`

- Component Editor right side shows the same exit
