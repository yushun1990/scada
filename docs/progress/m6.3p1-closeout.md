## Authority preserved

### Canonical managed SVG authority

`SvgVisualLayer.document` remains the canonical managed SVG representation.

`assetRef` remains a deterministic serialized derivative rather than a second authored authority.

There is no parallel DOM SVG renderer, per-tag React/Konva renderer, sidecar presentation tree or alternate evaluator.

### Private SVG target identity

Managed SVG target identity remains private and deterministic:

```text
preorder allocation
svg-tag-000001
svg-tag-000002
svg-tag-000003
...
```

Source SVG `id` is a display hint only and is not targeting authority. Imported `data-scada-tag` is not trusted targeting input.

### M8 resource closure

Distribution remains self-contained. Managed SVG serializes to a `data:image/svg+xml` resource and accepted raster assets remain supported self-contained `data:image/...` resources.

`blob:`, hidden remote resources and unsupported external dependencies fail closed at the accepted distribution boundary.

### M9 Attribute / Property authority

M6.3P1 did not flatten public state.

```text
Attribute = authored static configuration
Property  = runtime semantic value / binding target
```

Representative final proof:

```text
Property.state = running
        ↓ activates component-private rule
Attribute.runningColor = #7c3aed
        ↓ explicit target value source
svgTagId = svg-tag-000003
        ↓
style.fill = purple
```

The same result was proven in normal SCADA Workbench and the fresh standalone runtime.
