## 当前结论

- PR #196 的 Component toolbar 检查在菜单挂载前统计项目，得到 `0 !== 8`；Shell 检查在菜单挂载前判断显示/隐藏入口，走错分支。修正等待顺序，保留项目数量和面板几何断言。
- 素材放置代码仍查找 `.component-editor-shell`，当前容器已是 `.component-studio-shell`，导致画板未安装 drop 监听。U1 应改为显式画板引用，避免再次依赖外壳类名。
- 当前“方法／事件”无论选中什么都编辑组件公开契约，容易让用户以为是在编辑图层。U3 先明确组件与图层作用范围，不能用一套标题掩盖两种不同能力；也不能给普通图元虚构可调用方法或事件。
- 用户已确认：画布只操作整组，内部图层从树选择后可配置属性与行为；修改几何必须先拆分。白色画布需要增大显示面积，保持组件设计尺寸与存储数据不变。
