### PR #143 — managed SVG preorder tag-id parser fix

Merged as:

`main@996a111bdd9aa76f2126475fe796c45f7285e38b`

Root cause:

- `parseManagedSvgSource()` incremented the preorder counter before recursion but derived `tagId` only after returning from child recursion;
- nested `svg > g > rect` could therefore assign the final descendant index to multiple ancestors;
- duplicate private tag IDs were then correctly rejected by managed-SVG validation.

PR #143 captures each element's private tag ID immediately after preorder allocation and before child recursion, restoring the P1.0 stable preorder identity contract. A deterministic parser-authority guard was added to normal CI.

Evidence:

- main CI #945 passed;
- Deploy GitHub Pages #283 passed;
- Pages Browser Smoke #234 advanced beyond SVG import and failed later during save synchronization.

That advancement confirmed the parser repair hit the real import failure.

### PR #144 — persisted save-state smoke authority

Merged as the final accepted revision:

`main@ae5ae5253a00067b9ad27ade0c227b0b39ea7650`

The previous shared `saveAndWait()` waited for the transient `组件已保存` message. Product save first persists the component, then changes the hash from `#/components/new` to the saved component id; `App` keys the editor by route id, so the route transition remounts the editor and clears local message state. The toast was therefore not a stable persistence authority.

PR #144 changes only test infrastructure:

- new-component save waits for a real component route and a readable IndexedDB document;
- existing-component save waits for persisted `updatedAt` to change and the document to remain readable;
- normal CI syntax-checks the shared helper.

Final evidence:

- main CI #947 passed;
- Deploy GitHub Pages #284 passed;
- Pages Browser Smoke #235 passed the complete acceptance chain.
