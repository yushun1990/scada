# M6.2.6 Component Editor Header Alignment

Status: implementation complete · PR pending · manual visual smoke pending.

This is a focused Component Workbench chrome fix after M6.2.5 compact Inspector density. It changes no Component/Scene/Runtime behavior.

## Reported visual issue

In Component Editor:

- header contents were visibly shifted upward instead of sharing one vertical center line
- a pale gold horizontal protrusion appeared under the left half of the header

## Root cause

Shared `editor-chrome.css` intentionally uses:

```css
.editor-header .header-actions {
  display: contents;
}
```

This works for SCADA Editor because its header action container only contributes the explicitly positioned mode switch and document toolbar.

Component Editor contributes additional `header-message` and `component-status-pill` children. When flattened by `display: contents`, the status pill became a direct CSS Grid item without an explicit grid position. Grid auto-placement created an implicit second row. The draft pill uses `border-color: #fde68a`; when stretched by the grid, that border became the long gold line visible in the screenshot. The implicit row also displaced the intended vertical alignment.

Component Editor additionally overrode the shared 60px editor chrome row with a 56px shell row, making its header baseline inconsistent with SCADA Editor.

## Fix

Added `src/component-editor-header.css` as a Component Editor-only chrome override:

- restore Component Editor shell header row to 60px
- keep brand content explicitly vertically centered
- override Component Editor `.header-actions` back to a real right-side flex cluster
- keep status/message/save in that right-side cluster
- keep Design/Preview absolutely centered in the viewport
- remove the implicit Grid row instead of hiding or painting over the gold artifact

The fix is structural CSS; no hard-coded pixel offset is used to fake placement of the status pill.

## Architecture boundary

No changes to:

- bindings

- undo/redo

Verify Component Editor at normal desktop width:

- brand/back button/title are vertically centered in the 60px header
- Design/Preview is vertically and horizontally centered

- the pale gold protruding line is gone
- switching draft/ready status does not create a line or second header row
- save-success/error message does not alter header height
