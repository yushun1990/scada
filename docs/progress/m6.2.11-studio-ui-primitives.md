# M6.2.11 Studio UI Primitives

Status: implementation complete in branch · CI pending · manual visual smoke pending.

This slice turns the M6.2.10 visual foundation into reusable controls and removes the temporary fixed-position workspace-exit layout.

## Reported problems

- The project had no mature UI primitive/component dependency; ordinary controls were mostly native HTML plus layered feature CSS.
- Repeated button implementations allowed basic geometry defects such as text not feeling vertically centered.
- Component Editor `保存` and `工作台` were separated by a temporary `74px` reserved margin.
- `工作台` used muted gray text and did not communicate that it is an important navigation action.

## Decision

Adopt Base UI as the headless interaction/accessibility layer and keep SCADA Studio's existing design tokens as the only visual theme.

The current npm package is `@base-ui/react`; M6.2.11 starts from the current 1.6.x release line.

## Completed in code

- Added `@base-ui/react` dependency.
- Added `src/ui` primitive layer:
  - Button
  - IconButton
  - SegmentedControl
  - Tabs
  - Select
  - Checkbox
  - Tooltip / TooltipProvider
  - Separator
  - Toolbar exports
- Added `src/ui/ui-primitives.css`, loaded after the Studio foundation layer.
- Studio Button owns centering through `inline-flex`, `align-items:center`, `justify-content:center`, stable tokenized height and `line-height:1`.
- Added primary / accent / secondary / ghost / danger button variants.
- Component Editor:
  - removed the obsolete left back-button DOM
  - Design / Preview now uses the shared Base-UI-backed segmented control
  - Save uses the shared primary Button
  - Property / Action / Event navigation uses the shared Tabs primitive
- Workspace new/edit actions now use shared Button primitives.
- Reworked App-owned `工作台` navigation:
  - removed fixed-position rendering
  - removed `74px` toolbar margin reservation
  - portals the navigation action into the real editor `document-toolbar`
  - renders a real separator plus accent-secondary `← 工作台` button
  - remains route-owned by App so SCADA and Component editors share navigation semantics
- Deleted the obsolete `src/studio-navigation.css` fixed-layout hack.
- Added normative `docs/design/ui-primitives.md`.

```text

草稿  [保存]  |  [← 工作台]
```

The workspace action uses the primary blue family as an accent-secondary control rather than muted gray, while Save remains the only filled primary action.

## Architecture boundary

No changes to:

- SceneDocument / scene persistence
- ComponentDefinition / ComponentVisualDefinition
- Component package persistence
- Registry
- Runtime / bindings / behaviors
- renderer semantics
- undo/redo

The new state owned by Base UI is transient interaction state only.

## Incremental migration boundary

M6.2.11 does not rewrite every native input/button in one PR. The initial migration targets high-visibility repeated controls and establishes wrappers for later focused migration of SCADA Canvas Toolbar, Inspector Select/Checkbox controls and contextual tooltips.

Feature modules should use Studio wrappers rather than direct Base UI imports when a matching wrapper exists.

## Verification after CI / merge

Manual visual smoke should verify:

- Component Editor Save and Workspace actions are adjacent with only a normal action-group gap/separator
- Workspace is visibly interactive through the Studio accent family
- Save remains visually primary over Workspace
- button text is horizontally and vertically centered
- Component Design / Preview remains centered in the viewport and has stable active state
- Component Inspector tabs remain compact and keyboard operable
- Workspace primary/edit actions retain expected dimensions and hierarchy
- SCADA Editor receives the same inline Workspace exit without changing Design / Preview centering
- browser Back/Forward and `#/works` / `#/components` navigation semantics remain unchanged
- no document data changes when interacting with UI primitives

After visual acceptance, continue focused primitive migration only when useful; do not let wrapper coverage delay M6.3 Composite Renderer + Visual Style / Rules.
