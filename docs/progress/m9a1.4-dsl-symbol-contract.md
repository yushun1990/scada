# M9A1.4 — SCADA DSL symbol/type contract

Status: **active**.

Architecture authority: `docs/architecture/scada-dsl-v1.md`.

## Goal

Migrate the exploratory M6.5 parser/analyzer/catalog to the accepted DSL v1 surface after the Attribute / Property and Scene v8 authority split.

## Required authority changes

- reserve `$self` for the current component instance;
- reserve `$device` for its one primary bound device;
- remove arbitrary user/source root symbols from Scene DSL v1;
- `$self` exposes Properties / Actions / Events, never Attributes;
- assignment targets are `$self.<Property>` only;
- readable roots lower to stable structured component/primary-device references before persistence/runtime;
- reject old `component.*` and arbitrary `device/outlet/...` source syntax rather than silently reinterpret it;
- remove exploratory expression `if ... then ... else ...` and the `then` keyword;
- retain braced statement `if / else if / else`;
- implement the accepted `case <expression> { literal: ...; _: ... }` surface only through the existing structured semantic model, not by adding another runtime authority.

## Compatibility boundary

Persisted Scene semantics are already structured and remain runtime authority. This migration changes the editor/source language, not persisted semantic identity.

Old exploratory DSL source is not silently treated as v1 source. A useful parse/semantic diagnostic is required.

## Acceptance

- `$self.property = $device.property` parses, type-checks and lowers;
- `$self` Attribute assignment is rejected;
- `component.property` is rejected;
- arbitrary external source roots are rejected;
- completion advertises only `$self` / `$device` roots;
- `then` expression-if is rejected;
- braced `if` remains valid;
- `case` literal arms plus final `_` lower deterministically through existing Value/Behavior semantics;
- existing runtime/persistence tests remain green without introducing a DSL-text persistence dependency.
