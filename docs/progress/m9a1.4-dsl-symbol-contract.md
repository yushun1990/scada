# M9A1.4 — SCADA DSL symbol/type contract

Status: **accepted implementation slice; pending PR merge**.

Architecture authority: `docs/architecture/scada-dsl-v1.md`.

## Goal

Migrate the exploratory M6.5 parser/analyzer/catalog to the accepted DSL v1 surface after the Attribute / Property and Scene v8 authority split.

## Accepted authority

- `$self` is the current component instance.
- `$device` is its one primary bound device.
- parser references are exactly `root.capability`; Scene DSL v1 accepts only `$self` and `$device` roots.
- old `component.*`, `device.*`, arbitrary named roots and arbitrary `$foo` roots fail at the source-language boundary.
- `$self` capability discovery exposes Properties / Actions / Events, never Attributes.
- ordinary assignment targets lower only from `$self.<Property>`.
- `$device.<Property>` lowers to structured `{ scope: 'primary-device', property }` references; the concrete authoring-time device id is never persisted.
- the one-device capability catalog rejects more than one source.
- completion/click-to-insert emits only `$self` / `$device` source text.
- exploratory `if ... then ... else ...` and `then` are removed from the v1 authoring grammar.
- braced statement `if / else if / else` remains the only `if` surface.
- `case <expression> { ... }` supports scalar literal arms and one final `_` fallback; a one-statement arm may be direct and a multi-statement arm requires braces.

## Declarative / imperative control lowering

Braced `if` and `case` do not create a second runtime model.

Assignment-only control structures lower into ordinary structured Value Bindings:

```text
if / case source
    ↓
exhaustive branch assignment analysis
    ↓
ScadaDslSemanticExpression conditional tree
    ↓
Value Binding
```

The first slice deliberately fails closed when declarative branch ownership would be ambiguous:

- an assignment `if` requires a final `else`;
- an assignment `case` requires the final `_` fallback;
- every branch must assign the same set of `$self` Properties;
- a branch may not write the same Property twice;
- one control structure may not mix Property assignment and Component Action calls.

Action-only `if` / `case` continues to lower into ordered Behavior branches with the existing branch-entry/no-replay semantics.

`on $self.<Event> { ... }` accepts one `$device.<Action>(...)` target in this v1 slice and lowers to the primary-device structured action reference.

## Compatibility boundary

Persisted Scene semantics remain structured runtime authority. This migration changes the editor/source language, not persisted semantic identity.

Compatibility retained intentionally:

- persisted semantic `conditional` expressions remain executable even though expression-if can no longer be authored;
- persisted structured `scope: 'external'` references remain executable for accepted older artifacts;
- new DSL v1 cannot author those external named roots;
- Scene v8, Property propagation, Preview and standalone runtime do not depend on DSL text after lowering/persistence.

## Acceptance evidence

Dedicated deterministic checks prove:

- `$self.property = $device.property` parses, type-checks, lowers and runs;
- `$self` Attribute assignment is rejected;
- legacy/arbitrary roots are rejected;
- completion advertises only `$self` / `$device`;
- expression-if is rejected;
- braced `if` assignment lowers into exhaustive structured Value Bindings;
- `case` literal arms plus final `_` lower into Value Bindings or ordered Behaviors according to branch contents;
- case pattern typing is checked;
- Action argument/arity typing works with `$self` / `$device`;
- dependency extraction contains no authoring-time device id;
- read-only Action arguments do not become propagation triggers;
- one-device rebinding works without recompilation;
- fixed-point propagation, rollback, duplicate-writer/cycle rejection and derived invalidation remain intact;
- Scene v8 Preview accepts DSL v1 source and keeps authored Property fallbacks immutable;
- typed Action/Event Preview integration remains intact;
- persisted semantic IDs remain independent of source statement position and restore without reparsing DSL text;
- a manually constructed legacy external structured reference remains executable as compatibility data.
